# 净契｜合同脱敏台

面向合同审查场景的浏览器本地脱敏 MVP。

## 隐私边界

- 合同文件仅在使用者浏览器内解析和处理。
- 应用没有文件上传接口，不向服务器发送合同内容。
- 仓库只保存程序代码，不保存真实合同、测试附件或脱敏结果。
- 使用者仍需在导出前人工复核识别结果。

## 当前能力

- 输入：Markdown、DOCX；PDF 支持实验性文字提取（30 MB / 200 页以内），输出为 Markdown。
- DOC：旧版存储格式可能漏读内容，需用 Word / WPS 另存为 DOCX；仅修改后缀无效。
- PDF：逐页标记，空白提取页和文字过少页会提示；整份无文字、加密、明显解码异常或解析失败时停止导入。图片、扫描内容、印章、批注、附件及元数据不纳入输出，需逐页核对文字和阅读顺序。原 PDF 不会被脱敏。
- 输出：脱敏后的 Markdown 和脱敏报告。
- 识别：合同主体及简称、人员与联系方式、地址、账号、金额、日期、期限、比例及业务数据等。
- 处理：候选信息可逐项确认，金额可选择替换或保留。

## 本地运行

直接使用静态网页服务器打开项目根目录即可。入口文件为 `index.html`。

PDF 依赖为 Mozilla PDF.js（pdfjs-dist 6.3.289，Apache-2.0），随站点本地提供。部署须包含 `pdf-import.mjs` 和完整 `vendor/pdfjs/`，无需第三方 CDN。依赖接口参考：https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html 。

PDF worker 使用官方精简文件的 gzip 包，按 96 KiB 分成 `pdf.worker.part-00` 至 `pdf.worker.part-03`，通过 `pdf.worker.loader.mjs` 在浏览器本地合并、解压加载；打包不改动解析代码。发布包需保留全部四段和许可文件。PDF 导入需要支持 DecompressionStream 的浏览器。

> 本工具仍处于测试阶段，识别结果仅供辅助判断，不能替代人工审查。
